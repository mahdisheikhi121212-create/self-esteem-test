# Self-Esteem Test

A Python desktop application designed to help users reflect on and better understand their level of self-esteem.

## About the Project

Self-Esteem Test is a psychology-related application that presents users with a 10-question self-esteem questionnaire.

The main purpose of this project is to encourage self-awareness and help people better understand themselves.

## How It Works

1. The user enters their name.
2. The user clicks the **Start Self-Esteem Test** button.
3. The application presents 10 questions.
4. The user answers all questions.
5. After completing the test, a result window is displayed.

Based on the user's answers, the application reports the self-esteem level as:

- High
- Moderate
- Low

## Technologies Used

The application is developed with Python and uses:

- **Tkinter** for the graphical user interface
- **messagebox** for displaying messages and results
- **simpledialog** for input dialogs
- **SQLite3** for local data storage
- **random** for randomization
- **datetime** for working with dates and times
